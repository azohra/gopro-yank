A normal folder.
No lock-in.

Your photos and videos stay usable without GoPro Yank. Alongside them, you get a readable report, a library index, and checksums for the files that arrived.

Put it on your computer, a NAS, or an external drive.

Before you start

The useful fine print.

Cloud media
GoPro Yank reads it. It never changes or deletes it.
Interrupted runs
Files already completed stay completed; the next run picks up what remains.
“Complete”
Every downloadable original in the latest library list is present and has passed its saved-file check.
MultiClipEdit
GoPro does not offer these timelines as downloads, so they remain listed for manual export.
