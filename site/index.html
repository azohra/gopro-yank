What you get

A normal folder.
No lock-in.

Your originals land in an ordinary folder on your computer or external drive. Move it, copy it, or inspect it without GoPro Yank.

The folder includes an index, dated library lists, and an offline report. GoPro does not publish the camera’s original checksums, so GoPro Yank records a SHA-256 checksum as each file arrives and uses it for later checks.

The demo uses sample data. With your account, the first library view remains read-only until you confirm.

A one-way path

It reads from GoPro. It writes to your folder.

CLOUD MEDIA UNTOUCHED

GoPro Yank never changes or deletes media from GoPro.

YOU CONFIRM FIRST

You see the destination and download size before any originals move.

STOP AND CONTINUE

Completed files stay completed, so the next run picks up what remains.

LOCAL CLEANUP STAYS LOCAL

If you remove an archive through the app, only files recorded in its manifest are deleted. Unrelated files and the folder remain.

A clear finish line

Complete means present and checked.

DOWNLOADABLE MEDIA EXPORT COMPLETE means every downloadable original in the latest library list is present in your archive and has passed its saved-file check.

Still visible

Manual exports stay on the list.

GoPro does not offer every cloud item as a download. MultiClipEdit timelines remain clearly listed for manual export, so you know exactly what still needs attention.
