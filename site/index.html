What happens with your account and files.

Sign-in
Your browser opens GoPro’s website. Your password never enters GoPro Yank.
Before download
You see media counts, types, total size, the destination, and items that need manual export.
On disk
Original files, an offline report, a manifest, dated library lists, and SHA-256 checksums.
Long runs
Stop at any time. A later run keeps completed files and continues with what remains.
GoPro cloud
The app reads your library. It never changes or deletes cloud media.
Not downloadable
MultiClipEdit timelines remain listed for manual export instead of being marked complete.

GoPro Yank uses undocumented GoPro cloud endpoints. If GoPro changes them, the app may need an update.
